# Disease Prediction from Medical Data

Machine-learning project comparing Logistic Regression, SVM, Random Forest, and XGBoost.

## Quick Start
1. Create/activate a Python environment.
2. Install: `pip install -r requirements.txt`
3. For the included demo data, use:
   `DATA_PATH = "data/sample_medical_data.csv"`
   `TARGET_COLUMN = "target"`
4. Run `python train.py`
5. Run `streamlit run app.py`

You can replace the demo CSV with a properly formatted heart disease, diabetes, or breast-cancer dataset. This project is for educational use and is not medical advice.
